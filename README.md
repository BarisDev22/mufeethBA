# Mohamed Mufeeth Portfolio

A responsive React + Vite portfolio based on the supplied resume.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Customize

- Edit portfolio content in `src/main.jsx`.
- Replace `public/profile.jpg` with another portrait while keeping the same filename.
- Update colors and responsive styles in `src/styles.css`.

Note: Private resume details such as date of birth, marital status, nationality, passport number, and visa identifiers are intentionally not displayed publicly.
